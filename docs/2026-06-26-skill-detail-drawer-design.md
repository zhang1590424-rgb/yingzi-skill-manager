# 技能详情面板轻量化：右侧窄抽屉

## 问题

当前选中技能后，3 列网格硬切为「240px 窄列表 + 全宽详情面板」，存在两个明显体验问题：

1. **面积过大**：详情占满右侧全部宽度，网格消失变为窄列表，页面突变感强。
2. **关闭不方便**：只有右上角一个「✕」按钮可关闭，交互路径长。

用户高频场景是「看简介、应用/收回、调整标签」，属轻量操作，不需要全屏级面板。

## 方案

将详情面板改为 **右侧 340px 抽屉 + 半透明遮罩**，叠加在网格上方。网格始终保持原样，不再变形。

## 布局结构

```
app-shell (不变)
├── sidebar 160px (不变)
└── main-content
    ├── toolbar (不变)
    ├── SkillGrid 3列网格 (始终保留，选中时不消失)
    └── [选中时] 浮层 (position: fixed / absolute)
        ├── 遮罩层 (全区域，点击可关闭)
        └── 抽屉面板 (右侧贴边, 固定宽 340px, 高度撑满)
```

## 抽屉内容（从上到下）

| 优先级 | 区块 | 说明 |
|---|---|---|
| 1 | 标题 + 关闭按钮 | displayName 左对齐，关闭「✕」右上角 |
| 2 | 描述 | 1-2 行，超出截断 |
| 3 | 标签区 | 行内 chips，点击可编辑（复用现有 TagEditor） |
| 4 | 操作按钮组 | 应用到… / 收回全部 / 打开目录 / 删除 |
| 5 | 应用状态列表 | 各目标的软链接状态行 |
| 6 | SKILL.md 预览 | **默认折叠**，点击展开后可滚动查看 |

SKILL.md 默认折叠的理由：高频操作不涉及完整文档，折叠降低视觉重量，需要时展开即可。

## 关闭方式

提供 4 种关闭路径，确保随时可退出：

1. 点击遮罩区域
2. 按 Esc 键
3. 点击抽屉内关闭按钮
4. 点击网格中另一个卡片 → 切换到新技能详情（不关闭抽屉）

## 动效

| 阶段 | 元素 | 动画 | 时长 | 缓动 |
|---|---|---|---|---|
| 打开 | 遮罩 | opacity 0 → 0.15 | 200ms | ease-out |
| 打开 | 抽屉 | translateX(100%) → 0 | 300ms | ease-out-expo |
| 关闭 | 抽屉 | translateX(0) → 100% | 250ms | ease-out |
| 关闭 | 遮罩 | opacity 0.15 → 0 | 150ms | ease-out |

- 只动画 `transform` 和 `opacity`
- 尊重 `prefers-reduced-motion`：duration 归零

## 视觉细节

- 抽屉背景：实色 `var(--bg-surface)`，不用玻璃拟态
- 抽屉左边缘：`1px solid var(--border)`
- 遮罩颜色：`rgba(0,0,0,0.15)` — 极淡，暗示可点击但不压暗网格
- 抽屉内间距：`padding: 20px 24px`
- 无圆角（右侧贴边）
- 抽屉内可滚动（`overflow-y: auto`），工具栏区域不跟随滚动

## 删除的组件

- `SkillListPanel`（240px 窄列表）：不再需要，网格始终可见
- 网格→列表的条件渲染逻辑：移除

## 不变的部分

- SkillGrid 网格本身的布局和卡片样式
- TagEditor 组件逻辑（移入抽屉复用）
- DeployModal（应用弹窗仍从抽屉内触发）
- 侧边栏和工具栏

## 边界情况

- 窗口宽度 < 700px 时：抽屉宽度改为 `calc(100vw - 160px - 24px)`，避免超出
- 选中态切换：点击另一个卡片时抽屉不关再开，直接替换内容（可加 150ms 内容淡入）
- 键盘焦点：打开时焦点移入抽屉，关闭后焦点回到触发的卡片
